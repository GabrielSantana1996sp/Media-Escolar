#  School Grade Average (Média Escolar)

A simple web application that calculates a **student’s average grade** and determines whether they are **approved, need recovery, or failed**.  
This project was developed as part of programming exercises at **Etec**, using **HTML, CSS, and JavaScript**.

---

##  Features
- Input fields for multiple grades.  
- Automatic calculation of the **average score**.  
- Classification of the student’s status:
  -  Approved  
  -  Recovery  
  -  Failed  
- Responsive and easy‑to‑use interface.  

---

## Technologies Used
- **HTML5** → Page structure.  
- **CSS3** → Styling and layout.  
- **JavaScript (ES6)** → Logic for grade calculation and DOM manipulation.

## How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/GabrielSantana1996sp/Media-Escolar.git
   cd Media-Escolar
   ```
2. Open `index.html` in your browser.  
3. Enter the student’s grades in the input fields.  
4. Click **Calculate** to see the average and the student’s status.
